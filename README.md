# sdk-world

The convenience tier of the PS2 SDK: graphics, audio, input and other packages built on [sdk-core](https://github.com/ps2build/sdk-core) and resolved and built by [`ps2build`](https://github.com/ps2build/ps2build). Copyleft-licensed ports live here directly.

## Attribution

Several packages are based on code from the [ps2dev/ps2sdk-ports](https://github.com/ps2dev/ps2sdk-ports) project and its contributors. Others are ports of separate upstream projects (SDL2, gsKit and more); each package's `package.yaml` records its `origin:`, and the [available packages](https://ps2.techwritescode.dev/guide/available-packages) page links each one to its source. This repository is not affiliated with or endorsed by any of those projects; do not file issues about it against an upstream repository.

## Licensing

Each package's `package.yaml` records its `license:`; licenses vary by package. See the [available packages](https://ps2.techwritescode.dev/guide/available-packages) page for the list.
